Customer Segmentation Analysis using Python and K-Means Clustering to analyze 3,900 customer transactions, identify shopping trends, evaluate discount strategies, and develop targeted marketing recommendations.
# Customer Segmentation Analysis

## Project Overview

Customer Segmentation Analysis uses data analytics and machine learning to understand customer shopping behavior and identify meaningful customer groups. This project analyzes 3,900 customer transactions to discover purchasing patterns and develop targeted marketing strategies.

## Objectives

- Analyze customer shopping trends and purchasing behavior.
- Identify product categories where discounts may be beneficial.
- Explore spending patterns across age groups, seasons, and locations.
- Segment customers using the K-Means clustering algorithm.
- Recommend targeted marketing strategies for customer conversion, loyalty, and retention.

## Dataset Description

The dataset contains **3,900 customer transactions** with information about:

- Customer demographics
- Product categories and items purchased
- Purchase amounts and review ratings
- Shopping seasons and locations
- Discounts and promotional codes
- Subscription status and purchase frequency
- Payment methods and shipping types

## Tools and Technologies

- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Environment:** Jupyter Notebook / Google Colab
- **Techniques:** Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, Feature Scaling, K-Means Clustering

## Project Workflow

1. Data loading and inspection
2. Data quality checks
3. Exploratory Data Analysis
4. Discount and category analysis
5. Age-group spending analysis
6. Seasonal and location-based analysis
7. Feature encoding and standardization
8. Elbow Method and Silhouette Score evaluation
9. K-Means customer segmentation
10. Customer profiling and marketing recommendations

## Key Findings

- **Footwear:** Discounted transactions had an average purchase amount of $61.80, compared with $59.08 for non-discounted transactions.
- **Age Groups:** Average purchase amounts were relatively similar across age groups.
- **Seasonal Trends:** Fall had the highest average purchase amount at $61.56.
- **Location Trends:** Alaska had the highest observed average purchase amount at $67.60 among the locations analyzed.
- **Customer Segmentation:** K-Means clustering identified three customer segments based primarily on promotional engagement and subscription status.

*Note: These are descriptive findings. The observed differences do not establish that discounts or other factors caused changes in spending.*

## Customer Segments

### Cluster 0 — Promotional Non-Subscribers
- Customers using discounts and promotional codes without a subscription.
- **Recommended strategy:** Encourage subscriptions through membership benefits and targeted incentives.

### Cluster 1 — Regular Non-Promotional Customers
- Customers not using discounts or promotional codes and without a subscription.
- **Recommended strategy:** Focus on loyalty programs, personalized recommendations, and cross-selling.

### Cluster 2 — Subscribed Promotional Customers
- Subscribers who use discounts and promotional codes.
- **Recommended strategy:** Improve subscriber retention through personalized promotions, exclusive benefits, and repeat-purchase incentives.

## Conclusion

This project demonstrates how exploratory data analysis and K-Means clustering can help identify customer behavior patterns and support data-driven marketing decisions. The resulting segments provide a foundation for targeted customer conversion, loyalty, and retention strategies.
